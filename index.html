1. Printing Output

Use print() to show text on the screen. Text goes inside quotes.

print("Hello, World!")
print("I am learning Python")

2. Variables and Data Types

A variable stores a value. Common types: str (text), int (whole number), float (decimal), bool (True/False).

name = "Eljie"
age = 20
height = 1.65
is_student = True

print(name, age, height, is_student)
print(type(age))

3. Getting Input

input() reads what the user types (always as text). Wrap it in int() to get a number.

name = input("Your name: ")
year = int(input("Birth year: "))
print("Hi", name, "- you are about", 2026 - year)

In the compiler, type your answers in the STDIN box (one per line) before clicking Run.

4. Making Decisions (if / elif / else)

Indentation (4 spaces) tells Python which lines belong inside the block.

score = 85

if score >= 90:
    print("Excellent!")
elif score >= 75:
    print("Good job!")
else:
    print("Keep practicing")

5. Loops

Use for to repeat a set number of times, and while to repeat until a condition is false.

for i in range(1, 6):
    print("Count:", i)

n = 3
while n > 0:
    print("Countdown", n)
    n -= 1

6. Functions

A function is a reusable block of code. Define it with def and send back a result with return.

def add(a, b):
    return a + b

def greet(name):
    return "Hello, " + name + "!"

print(add(5, 7))
print(greet("Python"))
